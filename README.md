## 👋 Who I Am

I'm pursuing a career in **Modern Frontend Web Development**, with a long-term ambition to build sophisticated web applications and interactive, 3D web experiences.

My approach combines structured learning with hands-on project development. I focus on understanding core concepts, applying them in real projects, and gradually developing the engineering skills required to build reliable software.

I believe professional development is about more than writing code. It also involves thoughtful design, accessibility, maintainable architecture, performance, and solving real problems.

## 🎯 What I'm Focused On

- **Web Foundations:** Strengthening my understanding of semantic HTML, modern CSS, responsive layouts, and browser fundamentals.
- **JavaScript Development:** Building programming knowledge to create dynamic, interactive web applications.
- **Development Workflow:** Practicing Git, GitHub, version control, and professional project organization.
- **Project-Based Learning:** Turning concepts into practical websites and progressively more capable applications.
- **Engineering Quality:** Working toward accessible interfaces, efficient rendering, maintainable code, and dependable user experiences.

## ⚙️ My Engineering Principles

- **Master the essentials:** Prioritize foundational knowledge before adding unnecessary complexity.
- **Build to understand:** Apply what I learn through practical projects rather than relying only on theory.
- **Design for people:** Value accessibility, responsive interfaces, usability, and clear information architecture.
- **Write maintainable software:** Aim for readable code, sensible abstractions, and structures that can evolve.
- **Improve continuously:** Learn from implementation, debugging, feedback, and iterative refinement.
- **Think beyond the interface:** Understand how performance, security, testing, and deployment contribute to production-quality software.

## 🚀 Where I'm Heading

My long-term goal is to become a professional frontend engineer capable of designing and building complete, production-quality web experiences.

I'm particularly interested in the intersection of frontend engineering and creative technology: interactive interfaces, immersive 3D experiences, and thoughtful digital products.

As my frontend expertise develops, I also plan to expand into backend and full-stack engineering so I can understand and build applications across the stack.

## 🤝 Collaboration & Professional Growth

I'm interested in meaningful collaboration, practical problem-solving, constructive technical discussions, and projects that encourage continuous improvement.

My goal is to grow through building real software, developing sound engineering judgment, and contributing to useful digital experiences.
